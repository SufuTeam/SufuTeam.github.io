# 口袋阅读隐私政策页面

这是一个不依赖 JavaScript 的静态页面，设计用于发布到 GitHub Pages 的以下路径：

`/echoread/privacy/`

## 目录结构

```text
echoread/
└── privacy/
    ├── index.html
    └── styles.css
```

将 `echoread` 目录完整复制到 GitHub Pages 发布源的根目录即可。页面内资源均使用相对路径，部署到子目录时不依赖站点根路径。

## 本地预览

在本目录运行任意静态文件服务器，然后访问：

`http://localhost:8000/echoread/privacy/`

页面不包含统计、广告、外部字体、第三方脚本或其他跟踪资源。
